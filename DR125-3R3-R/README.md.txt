# DR125-3R3-R

Custom KiCad footprint, symbol, and 3D model resources for the DR125-3R3-R power inductor used in the DC-DC Boost Converter PCB.

## Description

The DR125-3R3-R is used as the main power inductor in the boost converter circuit.

A custom KiCad footprint and 3D model were configured to represent the physical component accurately in the PCB layout and 3D viewer.

## Specifications

- Part: DR125-3R3-R
- Inductance: 3.3 µH
- Type: SMD Power Inductor
- Series: DR125
- Application: DC-DC Boost Converter

## Files

| File | Description |
|---|---|
| `DR125-3R3-R.kicad_sym` | KiCad schematic symbol |
| `INDM1250X1250X600.kicad_mod` | Custom KiCad footprint |
| `DR125-3R3-R.step` | 3D STEP model |
| `DR125 3D.png` | 3D model reference image |
| `how-to-import` | Footprint/import instructions |

## Usage

The custom footprint can be assigned to the inductor in KiCad for PCB layout.

The STEP model is used for 3D PCB visualization and helps represent the physical size and placement of the component.

## Project Application

This component is used as the power inductor in the DC-DC Boost Converter PCB project.

## Software

- KiCad
- STEP-compatible 3D model support
