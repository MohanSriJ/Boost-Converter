# XL6009

Custom KiCad footprint, symbol, and 3D model resources for the XL6009 DC-DC boost converter module.

## Description

The XL6009 is used as the boost converter/regulator in the DC-DC Boost Converter PCB design.

This folder contains the KiCad symbol, custom footprint, STEP 3D model, and a reference image used for the PCB design and 3D visualization.

## Files

| File | Description |
|---|---|
| `XL6009.kicad_sym` | KiCad schematic symbol |
| `DPAK170P1435X465-6N.kicad_mod` | Custom KiCad footprint |
| `XL6009.step` | 3D STEP model |
| `XL6009 3D.png` | 3D model reference image |
| `how-to-import` | Footprint/import instructions |

## Usage

The footprint and symbol can be imported into KiCad and assigned to the XL6009 component during schematic and PCB design.

The STEP model is used for 3D PCB visualization.

## Project Application

The XL6009 is used in the DC-DC Boost Converter PCB project as the main boost converter module.

## Software

- KiCad
- STEP-compatible 3D model support

## Notes

The footprint and 3D model were configured to provide proper component placement and visualization in KiCad.
